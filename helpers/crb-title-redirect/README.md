# CRB Title Redirect

同一／近似タイトル、または同一作品ID（RJ/BJ/VJ）の投稿が重複した場合、**旧投稿 → 新投稿**へ 301 リダイレクトする補助プラグインです。

自動取り込みで同名・ほぼ同名の投稿が増えたとき、同一ドメイン内の重複コンテンツを検索エンジン向けに整理します。

## 動作（v1.1）

1. 公開時／一括スキャンで、同じ投稿タイプの公開投稿を比較
2. **完全一致**、または **近似キー一致**（`DL版…` / 末尾 RJ・BJ / `|[{…}]` などを除去）、または **同一作品ID** でグループ化
3. **新しい方**（投稿日が新しい／同日時なら ID が大きい）を正とする
4. 古い方に `_crb_title_redirect_to` を付け、旧 URL へアクセスすると **301**

## 要件

- WordPress 5.8+
- 投稿タイプ既定: `post`（設定で変更可）

## 設定

「設定 → CRB Title Redirect」

- 有効／無効
- 対象投稿タイプ
- 近似マッチ（既定オン）
- CRB 取り込み投稿のみ対象（`_crb_item_key`）
- 一括スキャン

REST（管理者）:

- `GET /wp-json/crb-title-redirect/v1/status`
- `POST /wp-json/crb-title-redirect/v1/rebuild`

## 手動で転送を止める

旧投稿のカスタムフィールド `_crb_title_redirect_disable` を `1` にすると、その投稿だけ転送しません。
