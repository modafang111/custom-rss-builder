Custom RSS Builder — 練習用サンプル（正本サーバー）

正本サーバー（123789.jp）では、これらの HTML を WordPress 固定ページ（販売ページの子ページ）として公開します。静的ファイル（この index.html）はインストール用のソースです。

パターン ページ 一覧の場所 1件ぶん
1 — div が並ぶ 01-simple-div.html （空欄） .crb-sample-news-item
2 — 箱 + 記事 02-list-wrapper.html .crb-sample-list .crb-sample-item
3 — ul / li 03-ul-li.html ul.crb-sample-ul li.crb-sample-li
4 — 入れ子 04-nested-feed.html .crb-sample-feed .crb-sample-feed_list_item
5 — table 05-table-rows.html table.crb-sample-table tbody tr

公開 URL の例: …/crb-practice-samples/（販売・練習トップ）、…/crb-practice-samples/crb-sample-simple-div/（各パターン）。クライアントのフィード編集では「選択したパターンを反映」→「対象 URL にサンプルページを入れる」が簡単です。
