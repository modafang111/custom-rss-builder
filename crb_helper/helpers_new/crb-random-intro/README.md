# CRB Random Intro

Custom RSS Builder（**Pro AI テキスト変換**）向けの補助プラグインです。

管理画面の **3 ボックス**（1 行＝1 候補）からランダムに行を取り、AI 変換の指示へ **自動で** 付け、取り込み本文の先頭にも保存します。  
変換結果／本文が投稿に保存されるため、**同じ記事を見るたびに文が変わることはありません**。

Custom RSS Builder 本体のファイルは変更しません。

## 要件

- WordPress 5.8+
- Custom RSS Builder（クライアント）+ Pro（AI テキスト変換）
- Gemini API キー（CRB ライセンス画面）

## 使い方

1. プラグインを有効化
2. **設定 → CRB Random Intro** でボックス 1〜3 に候補を入力（1 行＝1 候補）
3. フィード側で **AI テキスト変換を有効**にする（**対象スロットは不要**）
4. プレビューまたは取り込みを実行（既存投稿の編集画面では動きません）

タグやチェックボックスでの指定は不要です。

本文へ保存した組み合わせは履歴に残り、**同じ組み合わせは使い切るまで出ません**。使い切り後は自動リセットします。

### ボックス例

**ボックス 1**

```text
こんにちは。
おはようございます。
お久しぶりです。
```

**ボックス 2**

```text
元気いっぱいの私です。
また会いましたね。
```

**ボックス 3**

```text
何とも美しい空模様です
可愛いワンちゃんに出会いました。関係ない話ですいません。
とりあえず読んで下さい。
```

抽選例（AI へ渡る素材）:

```text
おはようございます。
また会いましたね。
可愛いワンちゃんに出会いました。関係ない話ですいません。
```

## 動作の要点

| 項目 | 内容 |
|------|------|
| タイミング | AI 実行時のみ（プレビュー／取り込み） |
| 指定方法 | なし（自動） |
| 固定 | AI の出力がスロット経由で投稿に保存 |
| RSS 配信 | CRB 側仕様どおり AI 非適用のため付与なし |
| 接続テスト | 付与しない |

CRB 本体に AI 指示用のフックが無いため、Gemini `generateContent` 送信直前のリクエスト本文だけを補助側で書き換えます。
