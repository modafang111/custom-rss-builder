## 9. サーバー側で無効化したとき（重要）

詳細手順・切り分けは **[LICENSE_REVOCATION_TEST_CASES.md](LICENSE_REVOCATION_TEST_CASES.md)**（SRV-* / CLI-* / INT-*）を参照。

正本でキーを **無効化（expired）** したあと、クライアントは **次にプラグインが正本へ問い合わせるタイミング**（管理画面を開く、フィード保存、RSS アクセスなど）で **即座に** 再確認し、**利用可=いいえ** になります（`20260604t` 以降・REST の `crb_ls_inactive` を正しく反映）。

- `20260604s` 以前は 403 応答を一時エラー扱いし **利用可が true のまま** になる不具合あり（`20260604t` で修正）。
- クライアント画面を開いていないだけでは変わりません（プッシュ通知は未実装）。
- プラン表示が Pro のままでも、**利用可=いいえ** なら Pro 機能は不可です。

## 10. 既知の落とし穴（テスト時メモ）

- **「その操作を実行する権限がありません。」** → WordPress ユーザー権限ではなく **API Secret 不一致** のことが多い。正本の Secret をコピーし直す。  
- **利用可=いいえ / 状態=有効の矛盾** → 一時的な通信エラー。ライセンス画面を開き直すか **状態を再確認**（`20260604p` 以降は自動修復あり）。  
- **Pro 有効化で無料キーが再送される** → 空欄で Pro 送信すると旧挙動あり。**Pro キーを必ず入力**（`20260604p` 以降は hidden `crb_pro_upgrade` で防止）。  
- **登録サイト URL** → 各 WordPress のサイト URL が正本に登録される。無料・スタンダードは **1 台のみ**、Pro は **同一キーで最大 10 台**まで有効化可。
